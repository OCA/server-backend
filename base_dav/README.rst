This module adds WebDAV support to Odoo, specifically CalDAV and
CardDAV.

You can configure arbitrary objects as a calendar or an address book,
thus making arbitrary information accessible in external systems or your
mobile device.

.. contents::
   :local:

Installation
============

This module requires the ``radicale`` and ``vobject`` Python libraries:

::

   pip install radicale vobject python-dateutil

Requirements:

- radicale >= 3.0
- vobject
- python-dateutil

Configuration
=============

Go to Settings > WebDAV Collections to:

1. Create new collections
2. Select the model (``res.partner``, ``calendar.event``, etc.)
3. Define domain filters (e.g. user-specific data)
4. Configure field mappings for vCard/vCalendar export

Available access rights per collection:

- Owner Only: only the owner can read/write
- Owner Write Only: everyone can read, only the owner can write
- Authenticated: all authenticated users can read/write

Usage
=====

After installation, users can access their data via CardDAV/CalDAV using
their Odoo credentials:

- CardDAV (Contacts): ``/.dav/{username}/{collection_id}/``
- CalDAV (Calendar): ``/.dav/{username}/{collection_id}/``

Example URL for contacts:

::

   https://your-odoo.com/.dav/admin/1/
